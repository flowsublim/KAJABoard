The `legacy/smb_gas/` tree contains a placeholder README and empty module directories. It contains no `.gs`, HTML, JavaScript, CSS, print template, manifest, Sheet schema, accepted patch, sample data, or call-site evidence. Therefore:

- every function named in Project Plan §40 is classified below (96 of 96);
- `Triggered By`, reads, writes, validation, and side effects are conservative inferences from the function name and §40 capability summary, not verified code facts;
- helper removal means the technical GAS function has no target endpoint; any business-facing formatting/navigation capability is retained in the target UI where needed;
- no claim can be made that all functions in the real SMB system are mapped;
- the Phase 0 gate remains blocked until the actual source freeze is supplied and delta-audited.

Notation: `Unknown (source absent)` explicitly means no implementation was available. `N/A` means the technical helper has no standalone business transition. Target service/view names are design anchors for traceability, not implemented code.
